# Frontend AgroLogic

Frontend estático feito somente com HTML, CSS e JavaScript nativo. Não requer Node.js, npm, framework ou etapa de build.

Com a API em execução, sirva esta pasta usando qualquer servidor de arquivos estáticos. Para desenvolvimento local:

```bash
python -m http.server 5500
```

Abra `http://127.0.0.1:5500`. O endereço da API é configurado na meta tag `api-base-url` de `index.html`.
